# Stage 2: Technician screens

**Goal:** an Access front end that lets several technicians work on SiteBase at the same time, each under their own login, with "who changed this?" on every record and a clear message instead of a silent overwrite when two people edit the same record.

**Date started:** 6 Nov 2026
**Environment:** Microsoft Access 64-bit, ODBC Driver 17 for SQL Server, `SiteBase_Dev`

---

## Decisions

- **Login:** the PCs are not on a Windows domain, so each technician gets a **personal SQL login**. The password is typed at log-in, used once to connect, and never stored. Access re-uses that connection for every screen.
- **Built by code:** the front end is generated by `frontend/src/modSiteBaseBuild.bas`, so it can be rebuilt any time and is version-controlled as text.
- **No deleting:** screens don't allow deletes. A record is retired by unticking **Active**, so its history stays intact.
